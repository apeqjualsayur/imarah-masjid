# Uploading a logo

Your masjid or surau logo shows at the top of the sidebar and in the phone app's header. Later it will also appear on e-receipts, kariah cards and monthly reports. Only the Pengerusi can change the logo.

Until there is a logo, Imarah shows the masjid's initials in a circle (for example "SB" for Surau Baru).

## Steps

1. Go to **Settings**, then **Masjid logo**.
2. Under **Upload a logo**, press the choose-file button and pick your logo.
3. Press **Upload**.
4. Check the **Preview**: the logo is shown as a circle, a square and at sidebar size.

To change the logo, repeat the same steps. The old logo is removed automatically.

To remove the logo, press **Remove logo**. The masjid's initials show again.

## Files accepted

- PNG or SVG only.
- Up to 1 MB.
- A square logo works best. The whole logo is shown, never cropped.

## Security

The logo is stored in a folder for your masjid only. Users of other masjids cannot see it. Links to the logo only work for one hour.

## If something goes wrong

- **"Only PNG or SVG files are accepted."** Your file may be a JPG or another type. Open the logo in a photo app and save it again as PNG.
- **"This file is larger than 1 MB."** Make the picture smaller (for example 512 x 512 pixels) and try again.
- **"This SVG contains code that is not allowed."** Some software saves extra code inside SVGs. Export again as "Plain SVG", or use PNG.
- **I cannot see the Masjid logo menu.** Only the Pengerusi can change the logo. Ask your masjid's Pengerusi.
